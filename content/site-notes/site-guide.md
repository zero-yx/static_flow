# 个人站的工作方式

这是 zero-yx 的个人技术站。首页使用 StaticFlow 的 Rust/Yew 界面，年度回顾来自个人分支发布的 GitHub Wrapped。

## 从这里开始

- [2026 年 GitHub 回顾](/standalone/github-wrapped-2026.html)：浏览本分支生成的年度页面。
- [文章归档](/posts)：查看本站已经发布的笔记。

## 内容与维护

本站本机版的笔记保存在 `content/site-notes/`。元数据与 Markdown 正文按相同文件名配对；修改后刷新页面即可读到更新。示例文章保留上游原署名，不自动发布为个人作品。

通过中央控制室访问本站。更新先经过本地 Git、构建和预览，再决定何时发布。
